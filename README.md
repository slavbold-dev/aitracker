# AI Task Tracker - Android приложение

Приложение для отслеживания повседневных задач с календарем и возможностью записи задач на день или определенное время.

## Функционал

- 📅 **Календарь** - навигация по дням (предыдущий/следующий день, переход к сегодня)
- ✅ **Задачи на весь день** - создание задач без привязки ко времени
- ⏰ **Задачи на конкретное время** - указание точного времени выполнения
- 📝 **Описание задач** - возможность добавить подробное описание
- ✔️ **Отметка выполнения** - отметка выполненных задач
- 🗑️ **Удаление задач** - удаление ненужных задач
- ✏️ **Редактирование** - изменение существующих задач

## Технологии

- **Kotlin** - основной язык разработки
- **Jetpack Compose** - современный UI toolkit
- **Room Database** - локальное хранение данных
- **Material Design 3** - современный дизайн
- **Coroutines & Flow** - асинхронная работа с данными
- **ViewModel** - архитектура MVVM

## Структура проекта

```
app/
├── src/main/
│   ├── java/com/aitasktracker/
│   │   ├── data/           # Room DAO и Database
│   │   ├── model/          # Модель Task
│   │   ├── ui/
│   │   │   ├── screens/    # UI экраны (CalendarScreen)
│   │   │   └── theme/      # Тема приложения
│   │   ├── viewmodel/      # TaskViewModel
│   │   └── MainActivity.kt
│   ├── res/                # Ресурсы (строки, цвета, темы)
│   └── AndroidManifest.xml
└── build.gradle.kts
```

## Сборка и запуск

1. Откройте проект в Android Studio
2. Дождитесь синхронизации Gradle
3. Запустите на эмуляторе или реальном устройстве

## Требования

- Android 8.0 (API 26) и выше
- Android Studio Hedgehog или новее

## Особенности архитектуры

- **MVVM паттерн** - разделение логики и UI
- **Repository pattern** - абстракция доступа к данным
- **Single Activity** - навигация через Compose
- **StateFlow** - реактивное обновление UI
